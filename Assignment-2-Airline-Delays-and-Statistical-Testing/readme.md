# Assignment 2: Exploratory Data Analysis & Statistical Hypothesis Testing

## Overview
This module consists of two comprehensive analytical studies covering large-scale exploratory data analysis and rigorous inferential statistical hypothesis testing:
1. **Exploratory Data Analysis of Airline Delays and Cancellations**: Analyzing temporal, carrier, and airport delay dynamics across multi-year flight records.
2. **Statistical Testing on E-Commerce Data**: Formulating and testing empirical business hypotheses using parametric and non-parametric statistical methods.

## Files
- `EDA_Airline_Delays.ipynb` - Jupyter notebook containing end-to-end data cleaning, aggregation, and visualizations for flight delays.
- `EDA_Airline_Delays_Report.pdf` - Formal academic report detailing methodology, patterns, and findings.
- `Statistical_Testing_Ecommerce.ipynb` - Implementation of statistical hypothesis tests, significance evaluations, and diagnostic visualizations.
- `Statistical_Testing_Ecommerce_Report.pdf` - Project report detailing statistical hypotheses, test assumptions, p-values, and conclusions.

## Techniques & Methodologies Used
- **Exploratory Data Analysis (EDA):** Multivariate distributions, outlier detection, temporal aggregation, cancellation root cause decomposition.
- **Parametric Hypothesis Testing:** One-Way Analysis of Variance (ANOVA) for comparing average revenue across categories.
- **Non-Parametric Testing:** Chi-Square ($\chi^2$) test of independence for customer segmentation and high-value purchase associations.
- **Post-Hoc Analysis & Effect Size:** Tukey's Honestly Significant Difference (HSD) test, Cohen's $f$, and Cramér's $V$.
- **Data Visualization:** Matplotlib and Seaborn statistical plots (Q-Q plots, distribution histograms, interaction heatmaps).
